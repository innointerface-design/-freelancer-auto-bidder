Safety first
◇
Enabling real bids requires verified permission.

Confirm that Freelancer allows unattended automatic bidding for your account and app. Then configure all required server environment gates, review pricing, and explicitly start automation. A dashboard switch cannot override those gates.

Server configuration

Set FREELANCER_OAUTH_TOKEN through your hosting secret manager. Set OPENAI_API_KEY only if you want AI-generated editor drafts. Restart the server after changing environment variables.

Live submission requires FREELANCER_DRY_RUN=false, FREELANCER_ENABLE_AUTO_BIDDING=true, FREELANCER_AUTO_BID_PERMISSION_VERIFIED=true, and a genuine FREELANCER_PERMISSION_REFERENCE. Keep dry-run enabled until permission and results are verified.
